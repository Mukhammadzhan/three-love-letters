# Учта мактуб, фақат сиз учун ❤️

Романтический сайт на HTML, CSS и JavaScript: три интерактивных конверта, письмо на узбекском, анимированная SVG-роза и оригинальная фотография с инструментальной музыкой.

## Как изменить подарок

- **Фото:** замените `assets/portrait.png` своим оригиналом с тем же именем. Изображение показывается полностью; лицо и содержимое не обрабатываются. При другом формате поправьте путь в `index.html`, в шаблоне `photo-template`.
- **Стихотворение и подписи:** отредактируйте `index.html`. Полное стихотворение находится в `poem-template`; `<br>` означает новую строку, `<p>` — абзац. Сохраните кодировку UTF-8.
- **Музыка:** мелодия синтезируется через Web Audio в `app.js`, в функции `startMusic`. Ноты задаются массивами `melody` и `chords`, скорость — `next += .43`. Это оригинальная программная мелодия, без чужих записей. Для своего аудиофайла добавьте его в `assets`, используйте HTMLAudioElement вместо синтеза и сохраните запуск через нажатие и остановку при закрытии. Используйте запись, права на которую принадлежат вам или разрешают публикацию.
- **Цвета:** переменные в начале `style.css`.
- **Предпросмотр ссылки:** файл `assets/preview.png` и метатеги Open Graph в `index.html`. При смене адреса обновите `og:url` и `og:image` на абсолютные адреса своего сайта. WhatsApp может некоторое время показывать старый предпросмотр из кеша.

## Публикация

Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save. Изменения в основной ветке публикуются автоматически. Сборка и внешние библиотеки не нужны.

Для локального просмотра: `python -m http.server 4173`, затем открыть `http://localhost:4173`.

## Доступность и приватность

Есть управление с клавиатуры, Escape для закрытия, возврат фокуса к конверту, прокрутка письма, отключение музыки и поддержка `prefers-reduced-motion`. Музыка запускается только после нажатия; при уходе со страницы и закрытии письма выключается. Внешние шрифты, аналитика и сетевые музыкальные сервисы не используются.

GitHub Pages — публичный сайт. Фотография и письмо доступны любому, у кого есть адрес сайта или репозитория. Лицензия на фотографию не предоставляется: все права на неё остаются у владельца.
